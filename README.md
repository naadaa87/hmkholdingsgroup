## 2. 폴더 구성

```
(저장소 루트)
├─ index.html            ← 메인  ※ 반드시 루트에
├─ group/  model/  affiliates/  news/  careers/  contact/  policy/
├─ assets/               ← 로고·회장 사진·모델 이미지
│   ├─ model/            ← 건물·층별·물류코어·밸류업 이미지 8종
│   └─ portfolio/        ← 보유 자산 사진 3종
├─ css/  js/
├─ 404.html  sitemap.xml  robots.txt
├─ _redirects  _headers
├─ _generator/           ← 페이지 생성기(수정용, 배포에 영향 없음)
└─ README.md
```

## 3. GitHub에 올리기

기존 저장소를 다시 쓰신다면 **안의 파일을 모두 지운 뒤** 올려 주세요.

1. 저장소 화면 → **Add file → Upload files**
2. **`choose your files` 버튼은 누르지 마세요.** 폴더 경로가 지워져 파일이 뒤엉킵니다.
3. 압축을 풀고 `hmk-website` 폴더 **안으로 들어가서**, 안의 항목을 전부 선택(Ctrl+A) → 브라우저 화면 위로 **드래그**
4. 목록이 `model/space/index.html`, `assets/model/building.jpg` 처럼 **슬래시가 들어간 경로**로 보이는지 확인 → **Commit changes**

**올라간 뒤 확인** — `index.html`이 루트에 있고, `model` 폴더 안에 `ai-sourcing`·`space`·`liquidity`·`assets` 네 폴더가 보이면 정상입니다.

## 4. Cloudflare Pages 설정

- Framework preset: **None**
- Build command: **(비움)**
- Build output directory: **`/`** (입력칸 왼쪽에 `/`가 이미 표시되는 화면이면 **비워둠**)

커밋하면 자동 재배포됩니다. 배포 후 아래 세 주소가 모두 열리면 정상입니다.

- `/` → 메인
- `/model/space/` → 공간수익화 모델
- `/model/assets/` → 보유 자산

## 5. 로고는 깨지지 않습니다

로고와 파비콘은 별도 이미지 파일이 아니라 **스타일 파일(css/style.css) 안에 데이터로 내장**되어 있습니다. 업로드 중 파일 하나가 빠져도 로고가 사라지는 문제는 발생하지 않습니다.
